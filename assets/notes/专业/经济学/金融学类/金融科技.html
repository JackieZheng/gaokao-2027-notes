金融科技

金融科技是经济学门类金融学类专业，是金融与计算机、人工智能人工智能交叉的新兴本科专业，毕业授予经济学学士学位。它既学习金融理论与实务，也学习编程、数据与机器学习，对口的研究生一级学科为应用经济学。随着量化投资与金融数字化的发展，这一专业的就业前景受到关注，顶尖高校毕业生进入量化机构的情况近年来明显增多。

背景与定位

金融科技（专业代码 020310T）属于本科金融学类，学制四年，授予经济学学士学位，与金融工程、金融数学、金融学、保险学、精算学、投资学同属一个大类大类。本科阶段没有理论经济学、应用经济学这类专业名称，它们是研究生的一级学科；本科的金融学类在读研时对口的一级学科为应用经济学。这意味着本科选择金融科技，读研升学的对口方向对应应用经济学。

金融科技不是纯金融、纯商科，而是金融与计算机、人工智能的交叉，核心是用人工智能、区块链、大数据、云计算改造金融行业，覆盖智能风控、量化交易、移动支付、数字货币、智能投顾、监管科技等场景。在选科选科要求上，「3+1+2」模式首选必选物理、再选多为不限，「3+3」模式绝大多数要求必选物理，少数要求物理加化学。它要求学生具备较强的数学基础，同时掌握编程、机器学习等技能。对于数学不错、物理相对薄弱但希望进入985院校985院校商科专业的考生，金融科技是一个值得考虑的方向。

学习内容与核心课程

金融科技的基础课程覆盖金融、技术与法律合规三线。金融基础包括微观经济学、宏观经济学、货币银行学、金融学、投资学、公司金融、金融市场学、会计学、计量经济学；技术基础以 Python 编程为核心，兼修 C++ 与 Java、数据结构与算法、数据库原理、计算机网络、概率论与数理统计；法律合规包括金融法、互联网金融法规、反洗钱与数据安全隐私保护。

专业核心课程围绕金融大数据、人工智能金融、区块链与数字金融三条主线展开。金融大数据包括金融数据挖掘、大数据分析、数据可视化与 Hadoop、Spark 技术应用；人工智能金融包括机器学习、深度学习、自然语言处理、智能风控与智能投顾；区块链与数字金融包括区块链原理、智能合约、数字货币、跨境支付与供应链金融科技。

专业特色方向细分为量化金融、风控与合规、产品与运营、区块链应用四类。量化金融涉及算法交易、高频交易、金融衍生品定价与量化策略开发；风控与合规涉及信用风险模型、反欺诈、反洗钱与监管合规自动化；产品与运营涉及金融科技产品设计、移动支付产品、互联网信贷与数字化运营；区块链应用涉及央行数字货币、跨境结算、供应链金融与数字资产。

实践教学包括 Python 数据分析、金融数据建模、数据库操作与风控模拟等基础实训，量化交易平台实操、区块链实验、智能投顾系统开发、支付系统测试等专业实训，以及银行、证券、互联网金融公司实习与金融科技项目开发。

院校格局

中央财经大学与上海财经大学是金融科技领域的两所代表性院校。中央财经大学开设金融工程、金融科技，其中金融科技与北京航空航天大学计算机专业联培为双学位；上海财经大学开设金融学、数字与智能金融（专业自由分流）。华中科技大学的金融科技同样与北航计算机联培，学校还设有数字经济与AIAI双学位，专业设置上包含加统计学的双学位、金融工程、金融科技、智能金融等方向，并非纯金融。

2026年录取数据显示，中央财经大学金融科技（北航计算机联培）在山东653分（位次4261）、辽宁662分（位次1487），金融工程、金融科技在山东644分（位次6047）、重庆638分（位次3492）；上海财经大学金融学、数字与智能金融在山东642分（位次7159）、重庆637分（位次3643）、辽宁649分（位次3011）。

除财经强校外，一些综合类与地方院校也开设金融科技相关专业。深圳大学的金融科技等专业对接深圳城市建设与金融产业，保研保研率6.87%（2026年数据），升学率32.3%（2024年数据）。此外，北京金融科技学院（原北京工商大学嘉华学院）是财经类民办院校，以金融学、会计学、国际经济与贸易为主力专业。

理工类院校是金融科技的另一支重要力量。北京邮电大学、南京邮电大学、电子科技大学、西安电子科技大学以计算机加金融双强见长，技术方向突出。对外经济贸易大学、西南财经大学、中南财经政法大学等财经强校金融底蕴深厚、就业资源顶级；北京大学、复旦大学、清华大学、浙江大学、上海交通大学、中国人民大学等综合类名校学科实力强、平台资源广。地方层面，天津财经大学、东北财经大学、山东财经大学、浙江工商大学、广东金融学院等区域认可度高、就业稳定。

华南理工大学同样开设金融科技，其院校层次与城市区位优势明显，录取分数却相对较低。该校金融科技被放入包含建筑类、智能交通与数字建造等接受度不高的专业组专业组，导致相关专业组在北京等省份不受待见。以北京为例，华南理工03专业组含七个专业，其中建筑类（建筑学、城乡规划）与智能交通与数字建造均需排除，考生难以在组内挑出六个可接受专业，故该校在北京的分数并不高。

就业前景

金融科技与金融工程专业在就业市场上有一个突出方向，即量化投资。如果学生的数学基础或人工智能、机器学习基础较为深厚，学金融工程、金融科技可以进入量化机构工作。近两年，上海交通大学上海高级金融学院学习金融工程、金融科技的学生中，有较多毕业生进入顶级量化机构，量化岗位年薪起步可达百万，就业形势很好。

在顶尖高校，金融科技的教学也在与AI深度结合。如中国人民大学财政金融学院有教师从事金融科技、金融工程、机器学习甚至大模型大模型研究，但此类方向并非主流，规模相对有限。对于985985分数段分数段的考生，可选赛道包括人工智能、芯片、生物医药、前沿医疗、金融科技等，金融科技是其中的重要选项。

就业方向上，传统金融机构的科技岗是主流且稳定的去向。银行金融科技部、智能风控、手机银行开发、大数据分析、数字化转型岗位在工商银行、建设银行、招商银行等广泛设置；证券与基金公司吸纳量化分析师、算法交易员、智能投顾与金融数据建模人才；保险公司布局保险科技、智能定损与大数据风控。互联网金融与科技巨头是薪资较高的热门板块，支付宝、微信支付、银联等支付清算机构，蚂蚁集团、京东科技、度小满、微众银行等互联网金融企业，以及腾讯金融科技、百度金融、华为云金融、字节金融等科技巨头的金融业务均大量招聘。区块链与数字资产领域提供区块链工程师、智能合约开发、数字货币研发等岗位；央行、证监会、银保监会与地方金融监管局的监管科技、合规审查、反欺诈、金融风险监测岗位也是对口去向。从薪酬看，金融科技应届生起薪普遍在十五万至三十五万元之间，头部机构量化与风控岗位可达三十五万至六十万元，高于传统金融与普通信息技术岗位。

需要客观看待的是，AI正在重塑几乎所有脑力劳动行业，金融领域也不例外。因此金融科技专业并非传统意义上的纯金融，它更注重技术与金融的结合，这也使其在就业上与纯商科有所区别。社会上有不要学金融的论调，但对顶尖高校及量化等细分赛道而言，金融科技的就业表现并不差。

金融科技的对口岗位并非金融科技专业的独有赛道。计算机科学与技术、软件工程等专业的毕业生同样大量流向银行金融科技部、互联网金融平台、券商与基金公司技术岗等方向，这也意味着金融科技岗的竞争不仅来自本专业，也来自编程功底更扎实的计算机类毕业生。对金融科技专业的学生而言，在校期间积累扎实的编程与数据处理能力，并争取进入银行、证券、基金等机构的实习，是提升就业竞争力的关键环节。

报考建议

金融科技适合数学基础较好、对计算机与金融交叉领域感兴趣的考生。对于分数达到985水平、希望进入商科专业的考生，金融科技是兼顾学校层次与专业前景的选择之一。对于数学不错但物理相对薄弱的考生，金融科技相较于纯工科更容易发挥数学优势。

报考时需关注院校的办学模式，中央财经大学、华中科技大学的金融科技与北航计算机联培为双学位，培养上更偏技术；上海财经大学的数字与智能金融实行专业自由分流，入学后有一定选择空间。考生应结合自身对金融、计算机的偏好，以及院校的录取分数与位次进行综合判断。

对于分数相对一般的考生，民办财经类院校也开设金融学、会计学等专业，但其院校层次与就业竞争力与公办财经强校差距明显，需谨慎权衡。整体而言，金融科技专业不应对金融行业一概否定，关键是看院校平台、自身能力与赛道选择是否匹配。

部分工科强校会把金融科技、经济管理等相对冷门的专业放入物理化学双选的专业组，这类专业客观上会拉低该校在部分省份的最低录取分数，形成所谓低分进名校的表象。考生需要辩证看待这一现象，最低分吃亏并不意味着该校整体实力偏弱，其新工科、带电工科方向的实际水平往往并不逊色。判断院校价值时应结合具体专业组的构成与自身对专业冷热的偏好，而不应单纯以最低分高低作为取舍标准。

以华南理工大学为例，该校在四川等省份的专业组中同时包含智能交通与金融科技，智能交通方向接受度不高，考生可在能源与动力工程与金融科技之间择一考虑；另一专业组含七个专业，排除食品科学与工程后其余专业均可接受。报考金融科技时，考生应关注目标院校金融科技所在专业组的整体构成，避免因组内混入难以接受的专业而被动进入组内其他方向。

大类 大类招生 —— 高校按学科门类或学科群进行招生的模式，学生入学时不分具体专业，完成大一/大二通识基础课程后按兴趣和成绩分流到具体专业。与细分专业招生相比，大类招生给学生更多专业选择空间。典型如‘工科试验班’‘经济管理试验班’‘社会科学试验班’等。

选科 新高考选科 —— 新高考制度下学生自主选择的科目组合。主流模式为3+1+2：语数英3科+物理/历史1科+化学/生物/政治/地理4选2；3+3模式：语数英3科+选考3科。选科决定可报考的专业范围。
